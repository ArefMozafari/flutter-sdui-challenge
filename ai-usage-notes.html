How I judged the fixes
"Prove the test fails without the fix"

Every fix PR reintroduces its own bug and shows the test failing, instead of just saying tests pass. That's what I actually read in the PR bodies — a green suite proves nothing if the test never could have caught it. It caught one of its own that way: the widget test for the submit lock stayed green with the state fix reverted, because it was covering a different half. Two tests, two halves, both proven.
